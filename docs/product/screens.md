# Экраны

В продукте планируется четыре экрана, которые покрывают весь путь клиента от входа до истории заказов:

1. **Авторизация** — экран входа. Ограничивает доступ к остальному сценарию: пока клиент не вошёл, остальные экраны недоступны.
2. **Профиль** — личный кабинет клиента, где он видит сведения о своём аккаунте.
3. **Оформление заказа** — конфигурация заказа: содержимое корзины, детали доставки и оплата.
4. **История заказов** — список прошлых заказов клиента.

> **Примечание о реализации.** Перечисленные выше экраны — это плановый набор, описанный в правилах продукта. На текущем этапе разработки код ещё не дошёл до них: в маршрутизаторе (`src/5_core/config/app.routing.config.ts`) пока определены только маршруты `Intro` (`/intro`), `Integrations` (`/integrations`) и `NotFound` (`/not-found`), а корневой маршрут `/` перенаправляет на `/intro`. По мере реализации продукта экраны будут появляться в коде и дополнять этот раздел.
