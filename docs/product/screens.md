# Экраны

В продукте планируется четыре экрана, которые покрывают весь путь клиента от входа до истории заказов:

1. **Авторизация** — экран входа. Ограничивает доступ к остальному сценарию: пока клиент не вошёл, остальные экраны недоступны.
2. **Профиль** — личный кабинет клиента, где он видит сведения о своём аккаунте.
3. **Оформление заказа** — конфигурация заказа: содержимое корзины, детали доставки и оплата.
4. **История заказов** — список прошлых заказов клиента.
