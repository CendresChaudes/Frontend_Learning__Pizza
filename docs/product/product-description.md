# Описание продукта

Проект — это сервис заказа пиццы. В нём есть меню, настройка заказа, корзина и оформление покупки. Задача проекта — спокойно отработать визуальную часть и работу с корзиной, а также последовательность шагов от начала и до конца: от попадания пользователя на сервис до успешной оплаты заказа.
