# Нефункциональные требования

Цели и ограничения, которые влияют на UI и архитектурные решения продукта.

- **UX**: страницы должны выглядеть просто и понятно — обзорный макет, очевидное основное действие, минимальная когнитивная нагрузка. Плотность без визуального шума: оператор весь день работает со списками и формами, поэтому интерфейс не должен отвлекать.
- **Адаптивность**: каждый экран должен работать и на мобильных, и на десктопе — макеты, размеры кликабельных зон и навигация подстраиваются под viewport. Не должно быть экранов, существующих только для мобильных или только для десктопа.
- **Поддержка браузеров**: задаётся в [.browserslistrc](/.browserslistrc) — `last 2 years` для `development`, `production` и `e2e`. Не хардкодьте списки браузеров в других местах: обновляйте `.browserslistrc`, а тулчейн (Rspack/Babel/Autoprefixer) подхватит настройки автоматически.
