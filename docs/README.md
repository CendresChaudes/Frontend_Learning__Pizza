# Документация

Индекс файлов документации проекта. Документация разделена на продуктовую (для людей) и кодовую (генерируется из исходников).

## docs/product/

Продуктовая и пользовательская документация на русском языке. Описывает продукт с точки зрения человека, а не агента.

- [Описание продукта](product/product-description.md) — что за продукт и зачем он нужен.
- [Глоссарий](product/glossary.md) — термины продукта: Продукт, Корзина, Доставка, Заказ, Оплата.
- [Роли](product/roles.md) — роли пользователей продукта.
- [Экраны](product/screens.md) — плановый набор экранов продукта.
- [Нефункциональные требования](product/nfr.md) — цели и ограничения по UX, адаптивности и поддержке браузеров.

## docs/app/

Кодовая документация (API-референс, генерируется из исходников, например через TypeDoc). Генерируется командой `pnpm run docs`; пока не создана и не входит в текущую задачу. Сюда не добавляются ссылки до тех пор, пока документация не сгенерирована.
